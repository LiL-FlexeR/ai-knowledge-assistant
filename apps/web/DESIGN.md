# S06 interface direction

The product and architecture documents under `docs/` own scope and contracts. This record owns only the presentation of Documents and Ask AI, both in Operate mode.

Refero MCP was unavailable. Reference lock: the installed Refero typography, craft-details and anti-ai-slop references, with Impeccable Operate guidance and the S06 brief. Direct implementation is authorized by the stage request and its specified simple shadcn workflow.

| Decision                                               | Reference and role                                                                      | Implementation                                                                  |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Quiet white canvas, one sans family, compact rem scale | Refero typography: one family for app UI; Impeccable Operate: precision and scanability | System sans, 16px body, 30px page titles, neutral ink                           |
| Two task screens and top navigation                    | S06 scope; familiar Operate navigation                                                  | Documents and Ask AI; no dashboard or chat history                              |
| Divided document rows and a single upload region       | Refero anti-ai-slop: containers need a purpose                                          | Rows carry metadata, status and adjacent actions; no decorative card grid       |
| Blue links/focus; semantic status colors               | Refero craft-details and Operate color roles                                            | Blue only for focus/links; green ready; red failure; text always names state    |
| Source reference labels and excerpts                   | Canonical API source union; craft-details focus guidance                                | Fixed S1–S10 anchors, physical pages or section/lines, keyboard focus on source |
| No bitmap imagery or animation                         | S06 task and constraints                                                                | Code-native UI only; no invented progress percentages                           |

Preserve readable type, 1px divisions, a restrained 6px control radius, strong focus rings and a 1080px content measure. Narrow screens stack actions and metadata. Reject decorative gradients, metric tiles, illustration and modal onboarding. Confirmations are reserved for deletion and paid reprocessing.
